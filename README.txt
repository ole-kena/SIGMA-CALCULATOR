SIGMA LOTS CALCULATOR V1.4

Files:
- index.html: calculator app
- manifest.webmanifest: installable web app metadata
- sw.js: offline cache support
- icon-192.png and icon-512.png: app icons

How to use:
1. Open index.html in a modern browser.
2. Enter balance, risk %, instrument, entry and stop-loss prices.
3. Press CALCULATE LOT SIZE.
4. To install on Android, host these files on HTTPS, open the page in Chrome, then use the browser menu > Add to Home screen / Install app.

The calculator uses illustrative standard contract assumptions: XAUUSD 100 troy ounces per standard lot; listed forex pairs 100,000 base units per standard lot. Lot sizes are rounded down to 0.01. Verify your broker's actual contract size, tick value, minimum volume and volume step before trading. Spread, commission and slippage are not included. V1 supports USD-denominated accounts and the instruments listed in the app.
